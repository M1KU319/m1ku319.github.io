费用流 & 二分图带权匹配

上一篇把二分图匹配转成了最大流。一单位流量代表一对匹配，容量限制保证每个点最多被选一次。如果每对匹配还有不同的收益，选择哪些边也会影响答案。

费用流给每条边再加一个单位费用。增广和反向边的操作仍然保留，只是找路径时，多了一笔要算的账。

先把目标说清楚

最小费用最大流的优先级是流量最大，其次费用最小。假设两种方案的流量分别为 33 和 44，即使后者贵一些，仍然选择流量为 44 的方案。

有些题目已经规定必须完成 KK 项任务，这时流量固定为 KK，只比较费用。能送出的最大流不足 KK 就无解，不能拿当前费用当答案。

设原边 ee 的流量为 fef_e，单位费用为 wew_e，总费用为

∑e∈Efewe. \sum_{e\in E} f_e w_e.

这里的 wew_e 是每单位流量的费用。一次增广推了 33 单位，路径每单位费用为 55，答案应该增加 1515。

沿用之前的邻接表，只需给 Edge 加上 w。c 继续表示残余容量，不能因为多了一个费用就把两者混起来。

反向边也要退费

最大流中，走反向边可以撤销之前送出的流量。现在原边上每送一单位需要支付 ww，撤销时就要退回 ww，所以反向边的费用是 −w-w。

反边仍然从容量 0 开始，正向边流过多少，才允许撤销多少。若题目原图本来就有两个相反方向的边，需要分别 add()，各自建立自己的残量反边。

这也让最短路变得稍微麻烦了一点。即使输入费用全部非负，增广之后仍然可能出现有正残量的负费用反边，直接把原费用丢给 Dijkstra 就不行了。

从最短增广路入手

EK用 BFS 找边数最少的增广路。费用流比较的是沿途费用之和，所以要在残量网络中找费用最小的源汇路径。

每找到一条路径，就取沿途残余容量的最小值作为增广量，再更新正反边。路径中可以有反向边，它们会把之前某些选择的费用抵消掉。

在初始残量网络没有负费用环的前提下，沿最短费用增广路推流，可以保持当前流量下的费用最优。一直推到无法到达汇点，就得到最小费用最大流。

固定流量下，两个可行方案的差可以在残量网络中分解成若干个环。如果存在费用更低的方案，其中至少有一个环的费用为负；反过来，沿负费用环调整流量，也能在流量不变时降低费用。最短路增广会保持残量网络中没有负费用环，这保证了每一步的最优性。后面的势能也能用来理解这个条件。

最直接的实现是每轮跑 SPFA，它能处理负费用边。SPFA 的最坏复杂度为 O(VE)O(VE)，每次增广都来一遍，会把时间花在重复的最短路上。这里使用初始 SPFA 加势能 Dijkstra，反向边仍然按原规则维护。

用势能调整边权

给每个点维护一个势能 h[u]，搜索时把边权改成

w′(u,v)=w(u,v)+h[u]−h[v]. w'(u,v)=w(u,v)+h[u]-h[v].

先看这样改会不会把最短路改掉。一条从 ss 到 tt 的路径上，中间点的势能一加一减恰好抵消，最后只剩

∑w′=∑w+h[s]−h[t]. \sum w' = \sum w+h[s]-h[t].

所有源汇路径都加上同一个数，费用大小关系不变。接下来只要让搜索涉及的 w′w' 非负，就可以用 Dijkstra。

第一次用 SPFA 求源点到各个可达点的最短距离，并令 h[v] 等于这个距离。由最短路的三角不等式

h[v]≤h[u]+w(u,v), h[v]\le h[u]+w(u,v),

可以得到可达部分的正残量边满足 w′(u,v)≥0w'(u,v)\ge0。如果一开始所有正残量边的费用都非负，直接令势能全为 0 即可。

之后每轮 Dijkstra 得到调整费用下的距离 dist，对所有可达点执行

新的调整费用为 w′(u,v)+dist[u]−dist[v]w'(u,v)+dist[u]-dist[v]，仍然非负。最短路上的边在更新后调整费用为 0，增广新产生的反边也为 0，下一轮还能继续用 Dijkstra。

实现时有两个地方要分开看。dist[t] 是调整后的费用，不能直接乘流量加进答案；下面沿 pre 回溯，累加原始 w 得到 path_cost。此外，既然后面要用所有可达点的距离更新势能，就让 Dijkstra 完整跑完，不在弹出汇点时提前返回。

pre[v] 保存进入 v 的边编号，重边也能准确更新。need 表示本次最多增加多少流量，返回值是本次增加的流量与费用。

给二分图匹配加上权值

源点、左右两侧和汇点的编号沿用上一篇。假设配对 (u,v)(u,v) 的收益为 weight，只需把对应边的费用设为 -weight。

连边 容量 费用
s -> u 1 0
u -> nL+v 1 -weight
nL+v -> t 1 0

一单位流量对应一对匹配，总收益为 -cost。这张图的初始正残量边从源点经过左部、右部，再到汇点，没有有向环，也就没有负费用环。

源点到左部、右部到汇点的容量都是 1，所以任何点都无法参与两对匹配。容量为整数，增广量也为整数，选中配对的净流量只能为 0 或 1。反过来，一组合法匹配可以沿对应的源汇路径各送一单位流量，两种方案一一对应。

到这里还不能急着跑满。题目究竟要最多的配对，还是最高的总收益，会影响停止条件。

考虑三条允许的配对，L1R1L_1R_1 的收益为 1010，L1R2L_1R_2 和 L2R1L_2R_1 的收益各为 44。

只选 L1R1L_1R_1，总收益为 1010。改成另外两对，匹配数增加到 22，收益却降到 88。所有边权都是正数，仍然会出现这种差别。

选中收益为 1010 的边以后，下一次增广会经过它的反向边。新增两条配对，撤销旧的一条，原始路径费用为

−4+10−4=2. -4+10-4=2.

这次增广让匹配数增加一，同时让收益减少二。算到这里，两种目标就很清楚了。

目标 处理方法
只要求总收益最大，允许少选 只有 path_cost < 0 才增广
先匹配最多，再让总收益最大 一直增广到没有路径
恰好匹配 KK 对，收益最大 最多增广到 KK，最后检查是否达到

最短增广路的边际费用不会下降，因此可选匹配模式在最短路径费用非负时可以停止。它会跳过费用为 0 的增广，所以不保证总收益相同时匹配数最多。

复杂度和使用范围

设原边数为 EE、点数为 VV，成功增广 AA 次。需要 SPFA 时，初始化最坏为 O(VE)O(VE)；不需要时只用 O(V+E)O(V+E)。这份实现的优先队列允许重复入堆，每轮 Dijkstra 为 O(V+Elog⁡(E+2))O(V+E\log(E+2))，一共至多 A+1A+1 轮搜索，空间为 O(V+E)O(V+E)。二分图匹配每次增加一对，因此 A≤min⁡(nL,nR)A\le\min(n_L,n_R)。

模板要求容量为非负整数、源汇不同，并且初始残量网络没有负费用环。有负费用环的题目可能仍然有有限最优解，只是需要额外处理，本模板没有消环步骤。

容量和费用都用了 long long，还要保证 pushed * path_cost 等中间运算不溢出，有限距离及势能的绝对值小于 INF。多测先 init_graph()；同一张图比较不同目标时，重新建图或恢复初始 e。直接再次调用会沿用已经修改的残量容量，返回的也只是这一次增加的量。
